1 Task Creation — Trigger Conditions

When a news item is approved, Planner task(s) are created depending on the baseline (Mandatory Date / Effective Date / Approval Date) and the resource allocation table.
ConditionOutcome
Mandatory Date is empty Create Task 1
Mandatory Date equals Effective Date Create Task 1
Approval happens after Mandatory Date Create Task 1
Mandatory Date exists and is after the approval date Create Task 1 + Create Task 2 for the Mandatory Date
  • Task 1 is always created on approval — Task 2 is only added on top when the Mandatory Date condition is met.
  • Maximum number of tasks per news item is capped at 2, regardless of how many dates are present.
